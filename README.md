# Data Analytics Internship - Task 2: Exploratory Data Analysis (EDA)

## 📌 Project Overview
This project is part of the CodeAlpha Data Analytics Internship. The goal is to perform Exploratory Data Analysis (EDA) on the scraped book dataset (`codealpha_scraped_books.csv`) to uncover insights, check data distributions, and detect outliers.

## 🛠️ Tools & Libraries Used
* **Programming Language:** Python 3.x
* **Environment:** Google Colab / Jupyter Notebook
* **Libraries:** 
  * `pandas` - Data cleaning and manipulation
  * `matplotlib` & `seaborn` - Data visualization and statistical plotting

## 📊 Analysis & Insights
* **Data Cleaning:** Extracted numerical values from the price text column and converted them to floats.
* **Distribution Analysis:** Analyzed the frequency and spread of book prices using histograms with KDE curves.
* **Outlier Detection:** Used box plots to identify price boundaries and potential outliers in the dataset.
